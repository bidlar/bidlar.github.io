# What is an NPU?

An **NPU (Neural Processing Unit)** is a processor designed to accelerate artificial intelligence and machine learning workloads.

Unlike a general-purpose CPU, an NPU is optimized for operations commonly used by neural networks.

## What are NPUs used for?

NPUs can accelerate tasks such as:

- Image recognition
- Speech recognition
- Generative AI
- Large language models
- Computer vision
- Background removal
- AI-powered photo and video processing

## NPU vs CPU

A CPU is designed to handle many different types of computing tasks.

An NPU is specialized for AI workloads and can often perform them more efficiently.

## Where are NPUs used?

NPUs can now be found in many devices, including:

- Smartphones
- PCs
- Tablets
- Cars
- Cameras
- Edge AI devices

Examples include Apple's Neural Engine, Qualcomm's Hexagon NPU, AMD XDNA, and Intel's NPU.
